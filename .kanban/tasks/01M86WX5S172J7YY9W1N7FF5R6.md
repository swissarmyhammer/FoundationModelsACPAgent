## Problem

Brief: .briefs/FoundationModelsACPAgent-spotlight-settings-2026-11-24.md. D214 gives Spotlight one switch for each kind of item. The configuration has only `sessions.spotlight`, at the user level only.

## Fix

- New section `spotlight` (`SpotlightConfiguration`): `enabled`, `sessions`, `archivedSessions` (false), `automatedSessions` (false), `tasks`, `library`, `externalSessions`, `settings`, `commands`. The other defaults are true.
- Each key is in the `settings` endpoint and tool at the user level and the session level.
- `sessions.spotlight` is removed with no alias. The user-level-only rule (`USER_LEVEL_ONLY`) had only that key, so it is removed too.

## Tests

`SpotlightSettingTests`: the defaults, `spotlight.tasks` at the user level, `spotlight.enabled` at the session level of one folder, a folder file, the old key is unknown, the tool at the session level, the tool description.
## Result

The new section and its tests are in. The full suite passed, except for one test that was already defective (`theReplayOpensTheOriginalCallWhenNoHistoryWasWritten`; it fails also at e0c9e50 when it runs alone). That test has its own card.
