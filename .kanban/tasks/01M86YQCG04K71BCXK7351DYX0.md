## Problem

The CI integration job of e0c9e50 failed: `peak memory increase 1706 MB`. The test read `ledger_phys_footprint_peak`, the peak of the whole process. The other integration suites (real models) run in the same process and set that peak before this test.

## Fix

The test reads the current physical footprint at each change that the build sends and at its end, and keeps the largest value. The increase is that value minus the footprint before the build.

## Result

A local run: memory increase 24 MB, first row 0.11 s, build 0.54 s.
