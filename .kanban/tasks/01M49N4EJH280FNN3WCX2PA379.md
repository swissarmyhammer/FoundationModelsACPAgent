title: 'swebench skills: wait loops, detached score, Docker preflight and score resume'
---
The two bench skills, `.claude/skills/swebench/SKILL.md` and `.claude/skills/swebench-score/SKILL.md`, have four problems. Each one occurred in a real run on 2026-10-05 or 2026-10-06.

1. **A wait loop does not stop.** A watch ran `while pgrep -f 'swebench_run.py bench/preds.NAME'`, and the pattern matched the watch's own `sh -c` command line. So the loop waited until the Monitor timed out after 30 minutes, and the score never ran. Fix: in each wait loop, use a pattern that cannot match itself, for example `'[s]webench_run.py ...'`.
2. **A long step that a Monitor starts dies when the Monitor stops.** A Monitor stops after 30 minutes at most. The score step must start with `nohup ... &`, detached, as the run step does. The watch then only waits.
3. **Docker preflight.** When the disk is full, or when Docker Desktop pauses its VM, `docker info` hangs and does not fail. This occurred two times on 2026-10-06. The preflight must use `timeout 10 docker info`, check the free disk space (`df -h ~`), and tell the user to restart Docker Desktop.
4. **Score resume.** When a score stops in the middle, run `swebench_score.py` again with the same `--run-id` and with `--instance-ids` for only the missing instances. `tally()` reads each `report.json` in `logs/run_evaluation/<run id>/`, so the result includes all instances. Write this in the swebench-score skill.
