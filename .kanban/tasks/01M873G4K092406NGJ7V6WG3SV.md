## Problem

Brief: .briefs/FoundationModelsACPAgent-spotlight-content-catalog-2026-11-24.md, part 6. The host must read the effective value of `spotlight.enabled` for a known folder, and get a change of it.

## Fix

- `SpotlightFolderSettings` (`contentCatalog.folderSettings`): `isEnabled(in:) async throws -> Bool` (the session level, else the user level, else true; the read starts the watch of the folder level) and `changes() -> AsyncStream<SpotlightSettingChange>` (`.user` or `.folder(URL)`). A change of another key gives no element.
- `SettingsStore.changes()` is `nonisolated` now: it uses only the nonisolated mutex of the subscribers, and a subscription then starts at the call.

## Tests

`SpotlightFolderSettingsTests`: the default is on; the session level of one folder turns that folder off and names it, and a change of `spotlight.tasks` gives no change; the user level turns each folder off.
## Result

Done as planned. The full suite passed (2869 tests, 1 known issue).
