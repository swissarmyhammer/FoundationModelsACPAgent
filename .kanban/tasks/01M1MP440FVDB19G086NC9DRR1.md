### What

cli-plan.md §5.12, rows 1 and 3. Two `Doctorable` conformances in
`Sources/FoundationModelsACPAgent/Doctor/`.

**`ConfigurationDoctor`**, category `configuration`:

- The configuration loads. A `ConfigurationError` becomes one `.error`
  whose message is the reason and whose fix names `acp-agent config
  show`.
- Every `ConfigurationWarning` the loader returns becomes one
  `.warning` — an unknown section, for example — with a fix that names
  the key and the file.
- Each layer path of §5.10: does it exist, is it readable, is it
  writable. A missing user or project layer is `.ok`, not a warning: the
  stack is meant to work with no file. An unreadable one is an `.error`
  with a `chmod` fix.

**`TranscriptsDoctor`**, category `transcripts`:

- The resolved transcript directory exists, or its parent is writable.
  A directory that cannot be created is an `.error`, and its fix names
  the `transcripts.location` key.
- `recording.level: off` makes this component report `isApplicable ==
  false`, so it stays silent rather than checking a directory nothing
  will write.

Both take the resolved `AgentConfiguration` and the `DotfolderStack`
through their initializer. Neither reads the process environment
directly, so a test can drive them with a temporary stack.

- [x] `TranscriptsDoctor`, with `isApplicable` for `recording: off`
