## The problem

An instance is lost when the model calls the `skills` tool. The tool fails,
the other tool call of the same turn is cancelled, and the turn ends with the
`_error` stop reason and no patch.

`django__django-13925`, instance 3 of the run of 2026-09-13. The whole
transcript is 5 lines, and the agent ran for 22 seconds:

```json
{"correlationID": "01M2E1YZV8ZCEEMMVJ4J7W5VRZ", "op": "skills",
 "tool": "skills", "kind": "completed", "outcome": "failed",
 "detail": "This operation failed while executing."}
{"correlationID": "01M2E1YZV8KAG272TCFAF9F32J", "op": "searchTools",
 "tool": "searchTools", "kind": "completed", "outcome": "cancelled",
 "detail": "CancellationError()"}
```

The record row of the instance:

```
total=57s clone=27s env=7s agent=22s bytes=0 files=0 stop=_error
```

The environment built correctly in 7 seconds. The agent then did no work at
all.

## Why it matters now

The model chooses when to call `skills`. Of the first three instances, one
called it, and that one instance was lost. So this is not a rare condition,
and every instance that calls the tool gives no patch.

## Two faults, and the second hides the first

1. **The tool fails.** This package has no skills yet, and the README says so:
   "There is no skill, and there is no workflow, because this package has no
   skills yet." A tool with nothing to give must answer with an empty list. It
   must not fail.
2. **The message says nothing.** `This operation failed while executing.` names
   no cause, no path and no underlying error. A person who reads the
   transcript cannot say what went wrong.

## The work

- Find why the tool fails with no skills present. A stack of skills that is
  absent, or empty, must give an empty answer.
- Give the failure a message that names the cause.
- A failed tool call must NOT cancel the other calls of the turn, and it must
  not end the turn. The model gets the failure as a tool result, and it goes
  on. Compare `searchTools`, which was cancelled here although nothing was
  wrong with it.

## When it is complete

- A call of `skills` with no skills present answers with an empty list.
- A failing tool gives a message that names its cause.
- A turn survives one failed tool call, and the agent keeps its other tools.
- `django__django-13925` runs to a patch.
