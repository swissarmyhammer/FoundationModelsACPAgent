## What
Design item 2: remove all `os.Logger` use and use `Logging.Logger` (swift-log). This task changes 4 of the 11 `os.Logger` sites. OTel 3 changes the session surface and OTel 5 changes the last 3. Approved design: `/private/tmp/claude-501/-Users-wballard-github-swissarmyhammer/9f4fa2e8-6833-46c6-bb95-5091ae3613fa/scratchpad/otel-design.md`.

Extras: FoundationModelsExtras OTel A to D are on Extras origin/main (HEAD 70ad74d, 2026-09-28). Run `swift package update FoundationModelsExtras` before you start this task.

Sites:
- [ ] `Sources/FoundationModelsACPAgent/Agent/SessionLifecycle.swift` — `lifecycleLogger` (category `SessionLifecycle`).
- [ ] `Sources/FoundationModelsACPAgent/Agent/ElicitationRelay.swift` — `relayLogger` (category `ElicitationRelay`).
- [ ] `Sources/FoundationModelsACPAgent/Commands/CommandRegistry.swift` — `commandLogger` (category `Commands`). Change its call sites in other files too.
- [ ] `Sources/FoundationModelsACPAgent/Tools/MCPComposition.swift` — `mcpCompositionLogger` (category `MCPComposition`).

Rules for each site (the same rules as OTel 3):
- Replace `import os` with `import Logging`. The label is `"FoundationModelsACPAgent.<Category>"`.
- Do not keep the logger as a global `let` or a `static let`: a logger made before a `TelemetryCapture` starts does not go to the capture. Make the `Logger` at the call, or as a stored property that the instance makes in its `init`. `MCPComposition` is an `enum` with static functions, so make the logger at the call there.
- Keep the level (`fault` → `.critical`).
- Move each interpolated identifier (session id, command name, MCP server name, elicitation id) into log metadata, with a key from `ACPAgentTelemetry.LogMetadataKey` (OTel 1). The message is a fixed string.
- No content rule (design item 4): no prompt text, response text, tool arguments, tool output, elicitation answer content or file content in a message or a metadata value. An MCP server `env` value or `headers` value is also secret: never log it.

## Acceptance Criteria
- [ ] The 4 files have no `import os` and no `os.Logger`.
- [ ] A refused client-supplied MCP server (for example an unknown transport) writes one record with the label `FoundationModelsACPAgent.MCPComposition` and the server name in metadata, and no `env` or `headers` value.
- [ ] A decline of an elicitation for an unsupported mode writes one record with the label `FoundationModelsACPAgent.ElicitationRelay` and the mode in metadata.
