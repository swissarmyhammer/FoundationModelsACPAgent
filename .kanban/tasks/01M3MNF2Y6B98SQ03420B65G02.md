Rules for each site (the same rules as OTel 3):
- Replace `import os` with `import Logging`. The label is `"FoundationModelsACPAgent.<Category>"`.
- Do not keep the logger as a global `let` or a `static let`: a logger made before a `TelemetryCapture` starts does not go to the capture. Make the `Logger` at the call, or as a stored property that the instance makes in its `init`. `MCPComposition` is an `enum` with static functions, so make the logger at the call there.
- Keep the level (`fault` → `.critical`).
- Move each interpolated identifier (session id, command name, MCP server name, elicitation id) into log metadata, with a key from `ACPAgentTelemetry.LogMetadataKey` (OTel 1). The message is a fixed string.
- No content rule (design item 4): no prompt text, response text, tool arguments, tool output, elicitation answer content or file content in a message or a metadata value. An MCP server `env` value or `headers` value is also secret: never log it.
