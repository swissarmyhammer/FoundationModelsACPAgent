## Why

Found during ^c7gphpm. `ToolCatalog.makeSkillsTool` gives the skills tool a session factory. Each call makes a new guided Router session (`profile.flash.makeGuidedSession(grammar:instructions:)`) and wraps it in `SelectionAgentSession`. FoundationModelsSkills (`SkillsToolAssembly.makeSelection`) passes this factory to `SelectionConfig(model:)`, so `SelectionTier` in FoundationModelsRanker calls it:

- one time for the cached root of each tier (`cachedRootSession()`), and
- one time for each run of an over-budget search (`oneOffSession(instructions:)` with a `.factory` source).

No code calls `RoutedSession.close()` on these sessions. After Router card R2 (01M3A1QPQMDJD33G9ANCC2TEZN), each one keeps a prompt cache entry until the byte LRU removes it. ^c7gphpm closes only the forks of these sessions.

## What

1. Learn the life of each session that the factory makes: the tier root lives as long as its `SelectionTier`; an over-budget session gets one prompt and is then dropped.
2. Close each session when its work ends, and write the choice in a comment on this task. One option: the factory returns an owner type that closes its Router session in `deinit`, as `SelectionAgentFork` does. The cached root must not close while the tier can still fork it.
3. If the close needs a change in FoundationModelsRanker or FoundationModelsSkills (for example a close on `AgentSession`), stop, and write a card on that board with `sah --cwd <repo> tool kanban task add`.

## Acceptance Criteria

- [x] Each guided Router session that the skills selection factory makes is closed one time when its work ends.
- [x] A cached tier root is not closed while its tier can fork it.
