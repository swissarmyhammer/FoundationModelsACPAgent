## Why

Found in the SWE-bench run `bench/preds.code-context.jsonl` of 2026-10-05. The two `_reasoning_limit` log lines show `context.fill=0.031`:

- `bench/run.code-context.log:2678`: `context.fill=0.031 ... tokens.in=144653 tokens.out=29046` (django__django-13710).
- `bench/run.code-context.log:8020`: `context.fill=0.031 ... tokens.in=1233016 tokens.out=45956` (django__django-13964).

The value is the same for two prompts whose input differs by a factor of 8.5. A person who reads the line thinks that the context was almost empty. Either the value is wrong, or the two numbers measure different things and the line does not say so.

## How the value is computed now

- `Sources/FoundationModelsACPAgent/Agent/EventProjection.swift:326-328`: at each submission end, `tokensIn += usage.tokensIn` (a sum over all submissions), but `contextFill = usage.contextFill` (only the last submission).
- `EventProjection.swift:144-149` writes `context.fill` with `%.3f`. `EventProjection.swift:438-443` derives the context size as `(tokensIn + tokensOut) / contextFill`. That size is wrong when the two values measure different things.
- The fill comes from the sibling repo FoundationModelsRouter: `Sources/FoundationModelsRouter/Session/RoutedSessionActorCompaction.swift:112-114` (`usageState.fill(contextTokens:)`), `Compaction/TokenBudget.swift:109-118` (`(input + output) / contextTokens` of the last measured render), `Session/RoutedSessionActorRecording.swift:81-83` (only a submission with a `.response` entry measures the render).
- `tokens.in` is thus the sum of each call's input. A tool loop sends the whole render again at each call, so `tokens.in` is not the context size.

## What to do

1. From the `generationCall` rows of the two transcripts, get the input tokens of the last call, and the `contextTokens` that the session uses for this model. Compute the true fill of the last call, and compare it with 0.031.
2. If 0.031 is wrong, find the cause (probable candidates, not yet proven: the last submission was a recovery after a compaction, so it measured only the summary; or `contextTokens` is wrong for this model) and correct it.
3. If 0.031 is correct, make the line clear: name the value as the fill of the last call, add the peak fill of the prompt and the context window size, and correct the derived size at `EventProjection.swift:438-443`.
