## Goal

Make the prompt states of the agent obey the failure and cancel rules of the ACP v2 prompt lifecycle (https://agentclientprotocol.com/protocol/v2/prompt-lifecycle). Terminals are out of scope.

## First step

Read the current behavior in `Sources/FoundationModelsACPAgent/Agent/PromptState.swift` (`running` at :163, `awaitingUser` at :95, `idle` at :111). Change only what is missing.

## What to change

1. Before an idle with an error, set each tool call that did not finish to `failed`.
2. Report `CancellationError` and the other abort errors as an idle with `cancelled`, not as an error. Send all final updates before the idle.
3. After the schema re-vendor, send `stopReason: error` with the `error` object `{code, message, data?}`.

## Dependency

Part 3 waits for FoundationModelsACP task ^vkz9jax (01M4GH1Y5HM48HBT9HAVKZ9JAX) "Re-vendor the v2 schema to get the error stop reason and the idle error object". It is on the FoundationModelsACP board. Parts 1 and 2 do not wait.

## Acceptance

- [ ] An error with open tool calls gives a `failed` update for each open call, and then the idle.
- [ ] A cancel gives an idle with `cancelled`, and all final updates come before it.
- [ ] After ^vkz9jax: an error gives `stopReason: error` with `{code, message, data?}`.
- [ ] Each case has a test that reads the wire messages.
