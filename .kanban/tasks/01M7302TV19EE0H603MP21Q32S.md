## What
Spec: TestudoApp/features/packages/foundationmodels-acpagent.md ACPA-1. Decisions D61, D70, D71, D90.

Today `SessionSetup` (`Sources/FoundationModelsACPAgent/Agent/SessionSetup.swift` ~1066-1080) always uses `surface.agents?.runner.defaultAgentInstructions()` for the base prompt. This task selects the agent of the session.

1. `Sources/FoundationModelsACPAgent/Agent/ConfigOptions.swift`: add a select config option `agent` (id `agent`, name "Agent"), next to `model`. Its values are the agents of `AgentRunner.catalog()` (FoundationModelsAgents) that a user can start (`isUserInvocable`), and the current value is the resolved agent of the session. Read the value from the `configOptions` of `session/new`, if the request has one, else from `_meta`; select the form that the ACP v2 wire types of FoundationModelsACP support, and record the choice in the doc comment. An unknown agent id gives `RequestError.invalidConfigOptionValue(id:)`. In this task the agent is set only at `session/new`; a `session/set_config_option` for `agent` after the start gives a clear refusal.
2. Resolve the session agent, in this order (D71):
   - the `agent` option, through `AgentCatalog.definition(named:)`;
   - else an `AGENT.md` at the root of the `cwd`;
   - else the default agent (`AgentCatalog.defaultAgent`), else `BuiltinInstructions`.
   Note: `cwd` is required in ACP `NewSessionRequest` (`AbsolutePath`, not optional), so the "no cwd" case of the spec does not occur on `session/new`. Do not add a path for it.
   Before you add a new parser for the `cwd` `AGENT.md`, check if the catalog already sees it (a local layer whose root `AGENT.md` is the agent `default`, `AgentLayerScan`). Use the catalog when it does.
3. Render the instructions of the resolved agent (body and `skills:` preload). `AgentRunner.defaultAgentInstructions()` renders only the default agent. If FoundationModelsAgents has no public API that renders a given `AgentDefinition` for a main session, make a card on the FoundationModelsAgents board (`sah --cwd ../FoundationModelsAgents tool kanban task add`) for `AgentRunner.sessionAgentInstructions(for: AgentDefinition)`, and make this task depend on it.
4. `Sources/FoundationModelsACPAgent/Instructions/InstructionsAssembler.swift`: when the client gives an `agent`, a `cwd` `AGENT.md` is project instructions, with the `AGENTS.md` text. When the `cwd` `AGENT.md` is the session agent, it is not repeated as project instructions. `AGENTS.md` is always project instructions.
5. Record the agent id of the session with the session record, so `session/resume` and `session/load` compose the same agent (`SessionResume.swift` `composeResumedSession`).

## Acceptance Criteria
- [ ] The `session/new` response lists an `agent` select option with the catalog agents, and its current value is the resolved agent.
- [ ] With `agent: X`, the session instructions hold the body of agent X, and a `cwd` `AGENT.md` shows as project instructions.
- [ ] With no `agent` and a `cwd` with an `AGENT.md`, that file is the session agent.
- [ ] With no `agent` and no `cwd` `AGENT.md`, the default agent is the session agent.
- [ ] An unknown agent id is refused with `invalidConfigOptionValue`.
- [ ] A resumed session has the same agent as before.
