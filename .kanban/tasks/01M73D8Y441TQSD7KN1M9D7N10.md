## What
FoundationModelsAgents main 79f1428 (task ^vn9ejqh, 2026-11-10) adds a last parameter `sandboxProbe: SandboxProbe = .live` to `AgentEnvironment.make`. It goes to both `SkillsTool.make` calls. With `.fixed(true)` and a skills registry in `.open` mode, `AgentEnvironment.make` throws `ToolModeError.openModeInSandbox`. With `.fixed(false)` or a `.sandboxed` registry, it succeeds.

Today `AgentsComposition.swift` ~94 calls `AgentEnvironment.make(...)` with no probe, so the skills tool always uses `.live` and a test with `.fixed` cannot reach it (gap found in ^bwgmkc0).

1. Update only the FoundationModelsAgents pin (`swift package update FoundationModelsAgents`, root and IntegrationTests) to a commit that has 79f1428.
2. `Sources/FoundationModelsACPAgent/Tools/AgentsComposition.swift`: pass `sandboxProbe: context.sandboxProbe` (from `CatalogContext`) to `AgentEnvironment.make`.
