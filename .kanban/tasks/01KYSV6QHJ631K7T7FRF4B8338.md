## What
Plan.md §4.1–§4.4. Create `Sources/FoundationModelsACPAgent/Transcripts/`:

- `TranscriptLocation.swift` — resolve the recording root from `transcripts.location`: `project` (default) → `<cwd>/.<name>/transcripts/`; `home` → shared root with the `-Users-…` slug scheme; absolute path → as given. The resolved root is what `makeSession(recordingRoot:)` receives (Router's `ke41yth` flat `<root>/<sessionId>/` layout does the rest).
- `SessionIndex.swift` — `sessions.jsonl`: append-only, one self-contained record per line. Record carries `sessionId`, `cwd`, generated `title` (first user prompt, cut to one line), `updatedAt` (RFC 3339, kept in the record), and the complete ordered `additionalDirectories` list (§4.6). Never persist client-supplied `mcpServers` (§7.3 — headers carry bearer tokens and this file is committed). Rebuildable from a scan of session directories (a damaged index is not load-bearing).
- On first write into a project's transcripts dir, materialize `transcripts/.gitattributes` with `linguist-generated=true` on `transcripts/**` and `merge=union` on `sessions.jsonl` (§4.3). Nothing under `.<name>/` gets ignored. No redaction anywhere (§4.4).
- `ProjectRegistry.swift` — `~/.config/<name>/projects.jsonl`: append `{path, firstSeen, lastSeen}` when a session starts in a new cwd; paths only, never content; skip stale entries on read (§4.5).
