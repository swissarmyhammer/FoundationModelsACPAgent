## What
Design item 2: remove all `os.Logger` use. This task changes the last 3 of the 11 `os.Logger` sites, and adds a guard test so that no new `os.Logger` or `OSSignposter` comes back. Approved design: `/private/tmp/claude-501/-Users-wballard-github-swissarmyhammer/9f4fa2e8-6833-46c6-bb95-5091ae3613fa/scratchpad/otel-design.md`.

Sites:
- [ ] `Sources/FoundationModelsACPAgent/Transcripts/JSONLines.swift` — `transcriptLogger` (category `Transcripts`). `SessionIndex.swift` and `ProjectRegistry.swift` call it; the call sites change only if the call shape changes.
- [ ] `Sources/FoundationModelsACPAgent/Configuration/ConfigurationLoader.swift` — `configurationLogger` (category `Configuration`).
- [ ] `Sources/FoundationModelsACPAgent/Instructions/InstructionsAssembler.swift` — `instructionsLogger` (category `Instructions`).

Extras: FoundationModelsExtras OTel A to D are on Extras origin/main (HEAD 70ad74d, 2026-09-28). Run `swift package update FoundationModelsExtras` before you start this task.

Rules (the same rules as OTel 3): `import Logging`, the label `"FoundationModelsACPAgent.<Category>"`, no global or `static let` logger (make it at the call or on the instance, so a `TelemetryCapture` sees it; `transcriptLogger` is shared by `SessionIndex` and `ProjectRegistry`, so give it as a function that makes a new `Logger`), the same level, a fixed message, identifiers in metadata with keys from `ACPAgentTelemetry.LogMetadataKey`. A file path is safe; file content is not (design item 4). A configuration value is not safe: log the section name or key, never the value.

- [ ] Add a guard test that reads each `.swift` file under `Sources/` and fails when a file contains `import os`, `os.Logger`, `Logger(subsystem:` or `OSSignposter`, or has a global or `static let` of type `Logger`. Use `PackageRoot` from `Tests/FoundationModelsACPAgentTests/Support/PackageRoot.swift` to find `Sources/`.

- [ ] The guard test fails when a file under `Sources/` has `import os` (check this one time by hand in the red step of `/tdd`, then remove the line).
