## Change

1. **The model transcript (Q83).** From the updates of the reader: each user message is a prompt; the agent messages of a turn are one response; each tool call is a short text in the response ("Tool <title>: <status>", then its text output cut at 4 KB); no thoughts; no images (one line with the type). It is a FoundationModels `Transcript`.
2. **The import.** `importSession` always makes a new session (Q85). The folder is `folder`, or the `cwd` of the source; it must exist and be readable, else a corrective. The name (Q84) is `name`, else the source title, else `<agent>-import`; the directory applies the next free number. Call `directory.importSession(_:transcript:)` of the Router, then write `session-history.json` with the updates of the reader in the folder of the new session, with the same writer as the fork. That write gives the turns to the search index. A failure after the Router write removes the new folder.
3. The session has origin `import`, kind `root`, and the provenance (the source agent, the source id, the source path, the date of the last record, the date of the import).
4. The import never changes, moves or deletes a source file.

## Tests

- `importSession` makes a session: `list sessions` shows it with origin `import` and the provenance; `session/resume` replays the imported updates; the export gives the Markdown of the fixture; a search finds a word of an imported turn; the first prompt goes to the stub model with the imported prompts and responses.
- A second import of the same source makes a second, independent session with the next free name; `previousImports` then has two entries.
- A source with no title gives `claude-code-import`.
- A missing folder gives the corrective and leaves no folder.
- The import does not change the bytes or the date of the source file.
