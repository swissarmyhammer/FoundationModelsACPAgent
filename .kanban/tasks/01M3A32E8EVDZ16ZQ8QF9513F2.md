## Why

"Turn" is a misleading word. The Router removes it (Router card `01M3A1F0KE9P9QPEVHXF33Q8GW`), and this agent must also stop using it for its own unit. The unit of this agent is one ACP `session/prompt`: from the `{}` response to the one `idle` terminator. Inside it, the Router has one request, one or more attempts, and one or more passes.

Name rule for this repository:
- **prompt**: the agent unit (one `session/prompt` to its `idle`).
- **request / attempt / pass**: only for Router units, with the Router names.
- Keep "turn" only for ACP protocol words: `end_turn` (`StopReason.endTurn`), `max_turn_requests` (`.maxTurnRequests`), and a quote of the ACP spec "prompt turn".

`PromptRequest` is the ACP wire type, so the agent type cannot be `PromptRequest`.

| `PromptTurn.endsTurn(_:sawOutput:)` | `endsPrompt(_:sawOutput:)` |
| the `turnState` parameter and property (`EventProjection`, `ElicitationRelay`) | `promptState` |
