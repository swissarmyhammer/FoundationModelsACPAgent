## Why

"Turn" is a misleading word. The Router removed it (Router card `01M3A1F0KE9P9QPEVHXF33Q8GW`). The Router now has a generation queue of submissions (`SessionEvent.submissionQueued/Started/Ended`), not turns. This agent must also stop using "turn" for its own unit. The unit of this agent is one ACP `session/prompt`: from the `{}` response to the one `idle` terminator. Inside it, the Router makes one or more submissions, and each submission makes one or more generation calls.

Name rule for this repository:
- **prompt**: the agent unit (one `session/prompt` to its `idle`).
- **submission** and **generation call**: only for Router units, with the Router names. The earlier Router words "request / attempt / pass" are obsolete.
- Keep "turn" only for ACP protocol words: `end_turn` (`StopReason.endTurn`), `max_turn_requests` (`.maxTurnRequests`), and a quote of the ACP spec "prompt turn".

`PromptRequest` is the ACP wire type, so the agent type cannot be `PromptRequest`.
